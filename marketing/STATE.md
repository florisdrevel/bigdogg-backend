## Sandbox limitation (applies to every run until changed)

This routine runs in an isolated cloud sandbox with outbound network restricted to a search tool only — it **cannot directly browse** higherlevel.nl, appwiki.nl, zzp-centrum.nl, ikwordzzper.nl, onderneming.nl, vergelijk-boekhoudprogramma.nl, or bigdogg.nl itself. All "research" is done via web search snippets/summaries, not by reading live pages. This means:
- Forum thread content (exact current replies, whether someone already answered, current date) is inferred from search snippets, not read directly. **Founder must open each link and sanity-check before posting.**
- Listing-site status ("is BigDogg listed") is "not found in search index" at best, never a confirmed "no."
- Any numeric fact (tax rates, KOR threshold, mileage allowance, payment terms) pulled from search should be verified against belastingdienst.nl or an accountant before publishing, since search summaries occasionally disagreed with each other (e.g. mileage rate was reported as both €0.23 and €0.25 for 2026).
